# SelfcareBot 🌟

Телеграм-бот для психологического самоухода. Сохраняй приятные воспоминания, получай рекомендации и возвращайся к хорошим моментам когда это нужно.

## ✨ Функции

### Бесплатные
- 💾 **Сохранение воспоминаний** — записывай приятные моменты из жизни
- 🎲 **Случайное воспоминание** — получи позитивный момент из прошлого
- 📋 **Список всех воспоминаний** — смотри историю
- 🗑️ **Удаление** — убирай ненужное
- 💡 **Рекомендации** — советы по еде, спорту и отдыху

### Premium (с оплатой)
- 🏷️ Теги для воспоминаний
- ⏰ Ежедневные напоминания
- 🤖 AI-советы на базе настроения
- ♾️ Безлимитное хранение

## 🎮 Команды

```
/start — начать работу с ботом
/save — сохранить приятное воспоминание
/remember — показать случайное воспоминание
/list — все мои воспоминания
/delete <id> — удалить воспоминание по ID
/recommend — получить совет (еда/спорт/отдых)
/buy — купить Premium-доступ
```

## 💳 Настройка оплат

1. @BotFather → `/mybots` → Bot Settings → Payments
2. Выбери провайдера:
   - **Stripe TEST MODE** (для тестирования)
   - **Stripe LIVE** (для реальных платежей)
   - **ЮKassa** (для РФ)
3. Скопируй `PAYMENT_PROVIDER_TOKEN`
4. Добавь в Railway Variables или в `.env`

**Тестовая карта Stripe:** `4242 4242 4242 4242` (любой CVV, любой срок)

## 🛠️ Технологии

- **Python 3.11+**
- **python-telegram-bot** 20.x — фреймворк для ботов
- **SQLite** — база данных
- **python-dotenv** — управление переменными окружения

## 📊 База данных

SQLite с двумя таблицами:
- `users` — информация о пользователях
- `memories` — сохранённые воспоминания

> ⚠️ **Важно:** Railway не сохраняет SQLite между деплоями.  
> Для продакшена используй PostgreSQL (можно добавить в Railway бесплатно).

## 🐛 Проблемы?

**Бот не отвечает:**
- Проверь логи в Railway (Deployments → View Logs)
- Убедись что `BOT_TOKEN` правильный

**Ошибка при оплате:**
- Проверь `PAYMENT_PROVIDER_TOKEN`
- Используй тестовую карту `4242 4242 4242 4242`

**База данных сбрасывается:**
- Railway не сохраняет файлы между деплоями
- Подключи PostgreSQL через Railway Dashboard
